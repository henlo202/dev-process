# Playbook: Planner agent

**Phase:** P3
**Reads:** approved requirements, architecture, test strategy
**Writes:** `docs/plan.md` (or issues)

## Steps
1. Slice the work vertically into tasks of about half a day of agent work each.
2. For each task, record the requirements and ACs, its dependencies, the files it touches, "done when", and its status.
3. Put a walking-skeleton task first, then order the rest by risk.
4. Check every task against the Definition of Ready.
5. Check that every in-scope requirement maps to at least one task, and list any that don't.
