# Traceability report (generated)

**What it is:** A report produced by the conformance checker that links each
requirement to the tests that reference it.

## It shows
- Requirements with **no** referencing test (warning)
- Test references to requirement IDs that do not exist (warning)
- Coverage by requirement: the number of referencing test locations

## Rules
- It is generated in CI on every PR. Never edit it by hand, and do not commit it.
- Read it at G4 and G5.
