# Increment demo

**What it is:** Evidence that shows the increment's outcome working, so the
Owner can approve on *outcomes* rather than on documents.

**Where:** linked from the increment brief's **Demo** section and from the PR
that completes the increment. Small demos (a terminal transcript, a few
screenshots) can be pasted inline. Recordings live wherever you keep media.

## A good demo
- Walks through each acceptance criterion in scope, in order.
- Runs against the real build: no mocks and no spike code.
- Shows at least one failure path (invalid input, a missing permission).
- Is reproducible: list the commands or steps used.

The demo complements automated tests. It does not replace them: every
acceptance criterion still needs a test that references its requirement ID.
