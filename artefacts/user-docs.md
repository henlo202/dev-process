# User documentation

**What it is:** Documentation for the people who use the software, organised
with the [Diátaxis](https://diataxis.fr) framework.

## Structure
| Folder | Diátaxis type | Answers |
|--------|---------------|---------|
| `docs/user/tutorials/` | Tutorials | "Teach me." A first success, step by step. |
| `docs/user/how-to/` | How-to guides | "How do I…?" Task-oriented recipes. |
| `docs/user/reference/` | Reference | "What exactly is…?" Commands, options, APIs. |
| `docs/user/explanation/` | Explanation | "Why…?" Concepts and background. |

Start with `docs/user/index.md`, and add folders only when you have content.
See the [documentation guide](../guides/documentation.md).
