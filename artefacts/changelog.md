# Changelog & release notes

**What it is:** `CHANGELOG.md` in [Keep a Changelog](https://keepachangelog.com)
format, plus user-facing release notes for each release.

## Rules
- Every user-visible change adds an entry under **Unreleased** in the same PR.
- Use the categories Added, Changed, Deprecated, Removed, Fixed and Security.
- At release (P4), move the Unreleased entries under the new version and date.
- Release notes are written for users: what changed for them, and what they need to do.
