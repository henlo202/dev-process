# Review cadence

| When | What | Output |
|------|------|--------|
| After each T3 release | Project retrospective | Actions routed to backlog / `AGENTS.md` / process |
| Quarterly | **Process review**: read the retrospectives and waivers from all active initiatives, and the open process issues | Process change PRs; a short note in `CHANGELOG.md` even if nothing changed |
| Yearly | **Pruning**: for every phase step, gate checklist item and artefact, ask "did this prevent a problem or help an agent this year?" | Removal or simplification PRs |

An agent can prepare the quarterly review: collect waivers and retrospective
actions across projects, group them by process area, and propose changes.
